# FinIndex project details

Full-stack financial analytics platform (Python, Flask, React, Pandas, NumPy, Matplotlib, SQL).
Built phase by phase: data processing, validation, SQL storage, calculation engine, Flask API, React dashboard, integration, quality, documentation.

Development principles: one phase at a time, Flask + React kept separate, Pandas/NumPy for processing, documented formulas, sample data always labelled as sample, never shown as real-time data, a working app at the end of every phase.

See README.md for run steps and the phase-to-code map.
